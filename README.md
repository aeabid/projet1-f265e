# متابعة التلاميذ — الدروس الخصوصية

تطبيق web لإدارة مشروع فيد التربوي: دروس الدعم (من الخامسة إلى التاسعة + السادسة عن بعد)، البرنامج التربوي السنوي، والدورات.
الولي يطّلع على تقدّم ابنه في دروس الدعم، والإدارة ترى كل شهر المداخيل والمصاريف والربح حسب كل نشاط.

## الأنشطة والمالية (الإدارة)

- **الرئيسية:** حوصلة الشهر (المقبوض والمدفوع والصافي لكل نشاط)، ثم أيقونات الدخول.
- **البرنامج التربوي** (سبتمبر → ماي): أقسام حسب الأعمار ومنشّطها، أطفال، حضور، ملاحظات (المستوى، متابعة المحتوى، السلوك)، مبلغ شهري وخلاص. الولي يتابع ابنه من حسابه، والطفل المسجّل في الدعم أيضًا يبقى شخصًا واحدًا.
- **الدورات** (عطل، صيف، مجموعات): مشاركون، معاليم، دفعات، مصاريف كل دورة وربحها.
- **الإطار والأجور:** أجور شهرية ثابتة تُسجَّل للشهر بنقرة.
- **المداخيل والمصاريف:** كراء، لوازم، مصاريف عامة، مداخيل أخرى.
- **المردودية المالية:** نقدًا وحسب الاستحقاق، والسنة الدراسية شهرًا بشهر.
- **المتخلّد بذمتهم:** ديون كل عائلة في كل البرامج، مع الأقدمية وتذكير واتساب.
- **الوصولات:** رقم تسلسلي واحد لكل الخلاصات، ووصل قابل للطباعة والإرسال.
- **التعريفات والتخفيضات:** معلوم كل مستوى وكل قسم، تخفيض شهري لكل تلميذ، تسبقة وأقساط.
- **تخفيض الإخوة:** نسبة للأخوين ولثلاثة إخوة أو أكثر، تُحسب شهرًا بشهر حسب عدد الأبناء المسجّلين (في الدعم أو التربوي).
- **معلوم التسجيل السنوي:** مرة واحدة لكل طفل في السنة الدراسية، حتى لو كان في البرنامجين.
- **المصاريف المشتركة:** تبقى وحدها، وتُوزَّع على الأنشطة بالنسب التي تحدّدها الإدارة (في المردودية المالية).

## بطاقة التقييم الشهرية

- **ملاحظة المعلم:** المستوى والسلوك معًا (كالبطاقة الورقية)، مع خيار «يراها الولي».
- **بطاقة التقييم:** من ملف التلميذ (الإدارة، المعلم لموادّه، الولي لابنه)، A4 للطباعة أو الحفظ PDF؛ وطباعة بطاقات قسم كامل من «بطاقات التقييم».
- **مستويات المعلم:** لكل مادة يدرّسها، المستويات التي يدرّس فيها (دون تحديد = الكل).
- **إدخال بطاقات القسم:** مادة واحدة لقسم كامل في شهر (المستوى والسلوك والملاحظة لكل تلميذ)، كما في البطاقات الورقية.
- **نظرة حسب القسم:** التلاميذ × المواد، آخر مستوى وسلوك في كل خانة، مع عدد كل مستوى.
- **الاستيراد من التطبيق السابق:** في «استيراد قائمة»، ملف `feed-suivi-handoff.zip` (التلاميذ، الصور، الملاحظات، المدرّسون)، دون تكرار.

## المراسلة والحسابات

- **رسائل الأولياء:** الولي يراسل أستاذ(ة) مادة أو الإدارة حول ابنه (دون ظهور اسم المدرّس)؛ المعلم يرى محادثات مادته فقط؛ عدد الرسائل غير المقروءة ✉️ في الشريط العلوي.
- **تسجيل المعلمين:** `/#/register-teacher`؛ الحساب لا يعمل حتى تفعّله الإدارة من صفحة «المعلمون».
- **الوضع الليلي:** حسب إعداد الهاتف أو الحاسوب.

## إدارة المركز

- **الرئيسية:** مؤشرات المركز والتنبيهات قبل حوصلة الشهر؛ جرس التنبيهات في الشريط العلوي.
- **المهام والمشاكل:** المسؤول، الأولوية، الأجل، والحالة؛ المعلم يرى المهام المسندة إليه.
- **الاجتماعات والقرارات:** المحضر، القرارات ومتابعتها، وتحويل القرار إلى مهمة.
- **الدورات والأنشطة:** دورات، أنشطة، رحلات ومخيمات (المكان، عدد الأماكن، الحالة، المشاركون، الخلاص والمصاريف).
- **كل تلاميذ المركز:** كل شخص مرة واحدة مع البرامج المسجّل فيها.

## فضاء التحفيظ (القرآن)

الشيخ يتابع حفظ ومراجعة طلبته أسبوعًا بأسبوع (`#/quran`). الإدارة تضيف المشايخ، والشيخ ينشئ مجموعاته (حسب المستوى) وطلبته.

- **حساب لكل طالب:** الاسم، اللقب، العمر، المستوى، المجموعة، ونسق المراجعة.
- **تحديد المحفوظ بطريقة سهلة:** ربع (البقرة 1، الأعراف 2، مريم 3، يس 4) ← أجزاء (كل حزبين) ← سور. يختار الطالب الحالة (✓ محفوظ جيد / ↻ يحتاج مراجعة / ✕ مسح) ثم يضغط على ربع كامل أو جزء أو سورة.
- **خطة المراجعة اليومية:** المحفوظ الجيد يُقسَّم ليُختم مرة كل 7 أيام (افتراضيًا)، وما يحتاج مراجعة يُكرَّر حسب نسقه الخاص. الأسبوع يبدأ يوم اللقاء مع الشيخ. الطالب يؤشّر على حصّة كل يوم.
- **الدرس الجديد (اللوح):** الشيخ يملي ثمنًا أو ثمنين، والطالب يقرؤه 70 مرة في الأسبوع: عدّاد (+1، +5) أو كتابة العدد مباشرة، مع المطلوب كل يوم حتى اللقاء الموالي، وإعلان «وصلت للهدف» مع العدد الجملي.
- **اللقاء:** الحضور (للمجموعة كاملة أو لكل طالب)، تقييم المراجعة، تقييم التسميع (الحفظ، الأداء، التجويد)، ملاحظة يراها الطالب، وإملاء الدرس الموالي في نفس النافذة.
- الشيخ يرى أين وصل كل طالب طيلة الأسبوع (شبكة الأيام: المراجعة وقراءات الدرس).
- صلاحية «فضاء التحفيظ» للإداريين في صفحة الصلاحيات (المدير له كل شيء). الجداول تُنشأ تلقائيًا عند أول استعمال (أيضًا على Supabase).

## الأدوار

| الدور | ماذا يستطيع |
|---|---|
| **الإدارة** | التلاميذ (صورة، مؤسسة، عنوان، مواد أو Pack، حالة: يدرس / في الانتظار / خرج / متوقف)، المعلمون، الأولياء (ب.ت.و)، المواد، استيراد قائمة، الخلاص الشهري (prorata، مجاني)، ساعات المعلمين وخلاصهم (من جدول الأوقات، غيابات، حصص إضافية، تسبقة)، تأكيد التسجيلات الجديدة، لوحة قيادة |
| **المعلم** | قائمة تلاميذه، جدوله، تسجيل الحضور للقسم، ملاحظات (السلوك / المستوى)، مهام عامة لكل القسم — **في مواده فقط**؛ وساعاته وخلاصه شهرًا بشهر طيلة السنة |
| **الشيخ** | مجموعاته وطلبته في فضاء التحفيظ: المحفوظ، المراجعة، الدرس، الحضور والتقييم |
| **طالب التحفيظ** | يحدّد محفوظه، يؤشّر على مراجعته اليومية، عدّاد قراءات الدرس، ويرى ملاحظات الشيخ |
| **الولي** | يسجّل نفسه وأبناءه من الرابط `/#/register`، ويرى أبناءه فقط (في دروس الدعم والبرنامج التربوي): الغيابات، الملاحظات، مهام القسم، والوضعية المالية شهرًا بشهر |

المستويات: من الخامسة إلى التاسعة أساسي + السادسة أساسي (عن بعد).
المواد الافتراضية: العربية، الفرنسية، الإنجليزية، الرياضيات (كل المستويات) وعلوم الحياة والأرض (التاسعة فقط).
الإدارة تزيد مواد أخرى من صفحة «المواد» وتحدّد في أي مستوى تُدرّس كل مادة.

## النشر: Netlify + Supabase

- الواجهة في `public/`، والـ API دالة Netlify في `netlify/functions/api.mjs` (منطقها في `lib/app.js`).
- **قاعدة البيانات: Supabase** (مشروع `wunachimbqwjdkgguhzf`). الدالة تتصل بها عبر المتغير السرّي `DATABASE_URL`
  في Netlify (Transaction pooler، المستعمل `feed_app` صاحب الجداول). دون هذا المتغير تعود إلى قاعدة Netlify القديمة.
- الجداول: `netlify/database/migrations/`. Netlify يطبّقها وحده على قاعدته؛ على Supabase تُطبَّق يدويًا بدور `feed_app` (وتُضاف إلى `supabase/setup.sql`). كل الجداول مغلقة بـ RLS.
- عند أول تشغيل على Supabase فارغة، تُنقل كل المعطيات تلقائيًا من قاعدة Netlify القديمة (`lib/db.js`).
- حساب الإدارة `admin` يُنشأ أول مرة بكلمة السر الموجودة في المتغير `ADMIN_PASSWORD` (في إعدادات المشروع على Netlify).
- الدخول بـ Google للأولياء: المتغير `GOOGLE_CLIENT_ID` (OAuth client من Google Cloud، المصدر المسموح: `https://taupe-gumption-4c4e97.netlify.app`). بدونه لا يظهر زر Google. الأولياء الجدد يرسلون طلب ربط أبنائهم، والإدارة توافق من «الحسابات ← طلبات أولياء Google».
- بيانات تجريبية (اختياري): `node scripts/seed-demo.js https://<الموقع> <كلمة سر الإدارة>`

## التشغيل محليًا

يتطلب Node.js 20.12 أو أحدث. قاعدة Postgres محلية تشتغل وحدها (في `data/`)، أو استعمل `DATABASE_URL`.

```bash
npm install
npm start                       # http://localhost:3000  (admin / admin123)
node scripts/seed-demo.js       # اختياري: بيانات تجريبية، كلمة السر 123456
```
