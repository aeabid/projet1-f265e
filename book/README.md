## التّعديل وإعادة البناء

- لتعديل درس : أُعدّلُ ملفّه في `lessons/`.
- لتغيير اسم المعلّم أو السّنة أو عنوان الكتاب : `CONFIG` في أعلى `build.py`.
- لتغيير الألوان والخطوط : `assets/book.css`.
- البناء (يتطلّب Python 3 و Node مع Playwright و `pdftotext`) :

```bash
python3 book/build.py
```

يُنتجُ `dist/kitab-nahw-sarf.html` و `dist/kitab-nahw-sarf.pdf`، ويحسبُ أرقامَ صفحات الفهرس تلقائيًّا.
