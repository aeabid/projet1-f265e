ملخّص الدّرس

ما هو الإعراب ؟

الإعرابُ هو تغيّرُ آخرِ الكلمة بحسب وظيفتها في الجملة. الاسمُ المعرب له ثلاثُ حالات :

جاءَ الوَلَدُ  |  رَأَيْتُ الوَلَدَ  |  سَلَّمْتُ عَلى الوَلَدِ

مرفوع
الفاعل - المبتدأ - الخبر(ونائب الفاعل)
منصوب
المفعول به - المفعول فيه للمكان وللزّمان - المفعول لأجله - الحال
مجرور
الاسم بعد حرف الجرّ - المضاف إليه

العلامات الأصليّة

الضّمّة للرّفع - الفتحة للنّصب - الكسرة للجرّ.

العلامات الفرعيّة

الواو (للرّفع) - الألف (للرّفع في المثنّى، وللنّصب في الأسماء الخمسة) - الياء (للنّصب والجرّ) - الكسرة بدل الفتحة في جمع المؤنّث السّالم.
جمعُ المؤنّث السّالم يُنصَبُ بالكسرة لا بالفتحة : رَأَيْتُ الطّالِباتِ. وبعضُ الأسماء لا تُنوَّنُ وتُجَرُّ بالفتحة (الممنوع من الصّرف) : مَرَرْتُ بِأَحْمَدَ - في مَساجِدَ.
لأُعربَ اسمًا أتّبعُ المسطرة : 1. الوظيفة ← 2. الحالة الإعرابيّة ← 3. نوع الكلمة ← 4. علامة الإعراب.
مثال محلول : نَجَحَ الطّالِبانِ ← فاعل - مرفوع - مثنّى - الألف.
التّمرين 1 : أُحدّدُ الحالةَ الإعرابيّة لكلّ وظيفة★ سهل
فاعلمفعول بهمبتدأمضاف إليهحالخبراسم بعد حرف جرّمفعول فيه
التّمرين 2 : أضعُ الحركةَ المناسبةَ على آخر الكلمة المسطّرة★ سهل
- رَسَمَ الطِّفْل صورَة جَميلَةً.
- جَلَسْتُ قُرْبَ النّافِذَة.
- الجَوّ مُعْتَدِلٌ.
- ذَهَبْنا إلى البَحْر.
التّمرين 3 : أختارُ الكلمةَ المناسبة★★ متوسّط
  1. فازَ ( اللّاعِبانِ - اللّاعِبَيْنِ ) بِالجائِزَةِ.
  2. شَكَرَ المُديرُ ( العامِلونَ - العامِلينَ ).
  3. كافَأَتِ المُعَلِّمَةُ ( التِّلْميذاتَ - التِّلْميذاتِ ).
  4. سَلَّمْتُ عَلى ( أَخوكَ - أَخاكَ - أَخيكَ ).
  5. ( المُهَنْدِسونَ - المُهَنْدِسينَ ) مُتَعاوِنونَ.

  2. رَأَيْتُ الفَتَياتَ في السّاحَةِ. ←
  3. جاءَ أَخا مَرْيَمَ. ←
  4. لَعِبَ الطِّفْلَيْنِ مَعًا. ←
