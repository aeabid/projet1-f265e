<h3 class="bar"><span class="n">1</span>المركّبُ النّعتيّ : منعوت + نعت</h3>
<div class="card"><p>النّعتُ (الصّفة) <b>يصفُ</b> المنعوتَ و<b>يتبعُه</b> في : التّعريف أو التّنكير - التّذكير أو التّأنيث - الإفراد أو التّثنية أو الجمع - الحركة.</p><p>• <b>العُصْفورُ</b> <span class="k">الصَّغيرُ</span> ← «ال» في الكلمتين &nbsp;&nbsp; • <b>طاوِلَةٌ</b> <span class="k">كَبيرَةٌ</span> ← بدون «ال»، مؤنّث &nbsp;&nbsp; • <b>التِّلْميذانِ</b> <span class="k">المُجْتَهِدانِ</span> ← مثنّى</p></div>
<h3 class="bar"><span class="n">2</span>المركّبُ الإضافيّ : مضاف + مضاف إليه</h3>
<div class="card"><p>المضافُ إليه <b>يُبيّنُ ويُوضّحُ</b> المضافَ، وهو <b>مجرورٌ دائمًا</b>.</p><p>• <b>قَلَمُ</b> <span class="k">الحِبْرِ</span> &nbsp;&nbsp; • <b>قَلَمُ</b> <span class="k">مُحَمَّدٍ</span> &nbsp;&nbsp; • <b>قَلَمُ</b><span class="k">هُ</span> (المضافُ إليه ضميرٌ متّصل)</p></div>
<div class="note"><b class="t">انتبه :</b> المضافُ <b>لا تدخلُه «ال»</b> و<b>لا يُنوَّن</b> : نقولُ «قَلَمُ الحِبْرِ» ولا نقولُ «القَلَمُ الحِبْرِ» ولا «قَلَمٌ الحِبْرِ».</div>
<h3 class="bar"><span class="n">3</span>المركّبُ البدليّ : مبدَلٌ منه + بدل</h3>
<div class="card"><p>الكلمتان <b>تدلّان على الشّيء نفسه</b> (البدل = المبدل منه).</p><p>• اسمُ إشارة + اسمٌ معرّفٌ بـ«ال» : <b>هٰذا</b> <span class="k">الوَلَدُ</span> &nbsp;&nbsp; • اسمٌ معرّفٌ بـ«ال» + اسمُ علم : <b>الوَلَدُ</b> <span class="k">أَحْمَدُ</span> - <b>الخَليفَةُ</b> <span class="k">عُمَرُ</span></p></div>
<h3 class="bar"><span class="n">4</span>المركّبُ العطفيّ : معطوفٌ عليه + حرفُ عطف + معطوف</h3>
<div class="card"><p>حروفُ العطف : <b class="k">وَ - فَـ - ثُمَّ - أَوْ</b>. المعطوفُ يتبعُ المعطوفَ عليه في الحركة : <b>الوَلَدُ</b> <span class="k">وَ</span>البِنْتُ - دَخَلَ <b>سامي</b> <span class="k">فَـ</span>أَخوهُ - <b>شايًا</b> <span class="k">أَوْ</span> حَليبًا.</p></div>
<h3 class="bar"><span class="n">5</span>المركّبُ بالجرّ : جارّ + مجرور</h3>
<div class="card"><p>يبدأُ بـ<b>حرف جرّ</b> وبعدَه <b>اسمٌ مجرور</b> : <span class="k">مِنَ</span> البَيْتِ - <span class="k">إلى</span> المَدْرَسَةِ - <span class="k">بِـ</span>القَلَمِ - <span class="k">لَـ</span>هُ.</p></div>
<div class="card c"><h4>التّوابع</h4><p><b>النّعتُ والبدلُ والمعطوفُ</b> تُسمّى التّوابع : تتبعُ ما قبلها في حركتها، فتكونُ مرفوعةً أو منصوبةً أو مجرورة : جاءَ الطّالِبُ <b>المُجْتَهِدُ</b> - رَأَيْتُ الطّالِبَ <b>المُجْتَهِدَ</b> - مَرَرْتُ بِالطّالِبِ <b>المُجْتَهِدِ</b>.</p></div>

::ex classify 1 | أُصنّفُ المركّباتِ في الجدول
cols: نعتيّ | إضافيّ | بدليّ | عطفيّ | بالجرّ
نعتيّ: البَحْرُ الأَزْرَقُ - كِتابٌ مُفيدٌ
إضافيّ: بابُ القِسْمِ - حَقيبَةُ سَلْمى
بدليّ: تِلْكَ الشَّجَرَةُ - هٰذِهِ البِنْتُ
عطفيّ: القِطُّ وَالكَلْبُ - الخُبْزُ ثُمَّ الجُبْنُ
بالجرّ: في الحَديقَةِ - عَلى الطّاوِلَةِ

::ex match 1 | أربطُ كلَّ مركّبٍ بنوعه
قَميصٌ جَديدٌ => مركّبٌ نعتيّ
سَيّارَةُ أَبي => مركّبٌ إضافيّ
هٰؤُلاءِ الأَطْفالُ => مركّبٌ بدليّ
الشَّمْسُ وَالقَمَرُ => مركّبٌ عطفيّ
مِنَ السّوقِ => مركّبٌ بالجرّ

::ex table 2 | أُكوّنُ المركّبَ المطلوب
head: الكلمة | مركّبٌ نعتيّ | مركّبٌ إضافيّ | مركّبٌ بالجرّ
البَيْتُ | [البَيْتُ الكَبيرُ] | [بَيْتُ جَدّي] | [في البَيْتِ]
السَّيّارَةُ | [السَّيّارَةُ السَّريعَةُ] | [سَيّارَةُ أَبي] | [بِالسَّيّارَةِ]
الحَديقَةُ | [الحَديقَةُ الواسِعَةُ] | [حَديقَةُ المَدْرَسَةِ] | [إلى الحَديقَةِ]

::ex fix 2 | أُصلحُ الخطأ في المركّبات الإضافيّة
القَلَمُ التِّلْميذِ => قَلَمُ التِّلْميذِ
بابٌ المَنْزِلِ => بابُ المَنْزِلِ
الحَديقَةُ المَدْرَسَةِ => حَديقَةُ المَدْرَسَةِ
كِتابٌ سامي => كِتابُ سامي

::ex fill 2 | أُطابقُ النّعتَ مع المنعوت (أكتبُ الكلمةَ بين القوسين بالشّكل المناسب)
اِشْتَرَيْتُ ثَوْبًا [جَديدًا] ((جَديد))
هٰذِهِ زَهْرَةٌ [جَميلَةٌ] ((جَميل))
نَجَحَ التِّلْميذانِ [المُجْتَهِدانِ] ((مُجْتَهِد))
عادَتِ الطُّيورُ إلى أَعْشاشِها [الدّافِئَةِ] ((دافِئ))
شَكَرْنا المُمَرِّضاتِ [النَّشيطاتِ] ((نَشيط))

::ex mcq 2 | أختارُ الشّكلَ النّحويَّ للعبارة الملوّنة
جاءَ ==طالِبُ العِلْمِ==. {نعتيّ | *إضافيّ | بدليّ}
جاءَ ==الطّالِبُ المُجْتَهِدُ==. {*نعتيّ | إضافيّ | عطفيّ}
جاءَ ==الطّالِبُ وَالطّالِبَةُ==. {بدليّ | *عطفيّ | بالجرّ}
جاءَ ==هٰذا الطّالِبُ==. {نعتيّ | إضافيّ | *بدليّ}
مَرَرْتُ ==بِالطّالِبِ==. {إضافيّ | عطفيّ | *بالجرّ}

::ex order 2 | أرتّبُ الكلماتِ لأُكوّنَ جملًا، ثمّ أضعُ خطًّا تحت المركّب الإضافيّ

::ex html 3 | أستخرجُ المركّباتِ من الفقرة وأُحدّدُ نوعَها
<div class="intro">في صَباحٍ مُشْمِسٍ، خَرَجَ الطِّفْلُ يوسُفُ مَعَ أَبيهِ إلى حَقْلِ الزَّيْتونِ. حَمَلَ يوسُفُ سَلَّةً صَغيرَةً، وَحَمَلَ الأَبُ السُّلَّمَ وَالعَصا. قالَ الأَبُ : «هٰذِهِ الشَّجَرَةُ قَديمَةٌ».</div>
