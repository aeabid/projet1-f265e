حدثٌ يقعُ الآن أو سيقعيَكْتُبُ - تَلْعَبُ - نَشْرَبُ
يبدأُ بأحد حروف المضارعة
يقبلُ السّين : سَيَكْتُبُ
الأمر
نطلبُ به القيامَ بالفعلاُكْتُبْ - اِلْعَبْ - اِشْرَبْ
يقبلُ ياءَ المخاطبة : اُكْتُبي
نُوجّهُه إلى المخاطَب

حروف المضارعة : «أَنَيْتُ»

أنيت
أَنا : أكْتُبُنَحْنُ : نَكْتُبُهُوَ / هُمْ : يَكْتُبُأَنْتَ / هِيَ : تَكْتُبُ

كيف أصوغُ الأمرَ ؟

  1. آخذُ المضارعَ مع «أَنْتَ» : تَكْتُبُ
  2. أحذفُ حرفَ المضارعة : ـكْتُبُ
  3. إنْ بدأ بساكن أُضيفُ همزةَ وصل : اُكْتُبْ
  4. أُسكّنُ الآخر : اُكْتُبْ

الأمرُ لا يكونُ إلّا للمخاطَب (أَنْتَ - أَنْتِ - أَنْتُما - أَنْتُمْ - أَنْتُنَّ). وليس كلُّ فعلٍ يبدأُ بالتّاء مضارعًا : «تَعَلَّمَ» فعلٌ ماضٍ لأنّه يقبلُ تاءَ التّأنيث (تَعَلَّمَتْ) ولا يقبلُ السّين.
لأعرفَ صيغةَ الفعل : أُجرّبُ السّين ← إنْ قَبِلَها فهو مضارع. أُجرّبُ تاء التّأنيث ← إنْ قَبِلَها فهو ماضٍ. إنْ كان طلبًا موجَّهًا إلى المخاطَب فهو أمر.

يَسْتَيْقِظُ سامي باكِرًا، يَغْسِلُ وَجْهَهُ، يَلْبَسُ ثِيابَهُ ثُمَّ يَذْهَبُ إلى المَدْرَسَةِ.

إصلاح تمارين الدّرس 8

التّمرين 1

ماضٍ : ذَهَبَ - سافَرَتْ - أَكَلْنا. مضارع : يَرْسُمُ - نَقْرَأُ - تَسْبَحُ - أَلْعَبُ. أمر : اِجْلِسْ - اُدْخُلي - اِسْمَعوا.

التّمرين 2

فَتَحَ : تَفْتَحُ - اِفْتَحْ . جَلَسَ : تَجْلِسُ - اِجْلِسْ . شَرِبَ : تَشْرَبُ - اِشْرَبْ . كَتَبَ : تَكْتُبُ - اُكْتُبْ

التّمرين 3

نَحْنُ رَسَمْنا - أَنْتِ تَلْعَبينَ - هُمْ نَجَحوا - أَنْتُمْ اِسْتَمِعوا - أَنا أَفْهَمُ - هُما يَخْرُجانِ

التّمرين 4

تَعَلَّمْتَ : ماضٍ (يقبلُ تاءَ التّأنيث : تَعَلَّمَتْ) - اِسْتَمِرَّ : أمر (طلبٌ موجَّهٌ إلى المخاطَب) - أَفْتَخِرُ : مضارع (يبدأُ بالهمزة ويقبلُ السّين) - اِبْتَسَمَ : ماضٍ - سَأَجْتَهِدُ : مضارع (دخلتْ عليه السّين)

التّمرين 5

اِسْتَيْقِظي باكِرًا، اِغْسِلي وَجْهَكِ، اِلْبَسي ثِيابَكِ ثُمَّ اذْهَبي إلى المَدْرَسَةِ.
