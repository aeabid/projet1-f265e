::discover
@map الهمزةُ المتطرّفة | أنظرُ إلى ما قبلها
- أَنْشَأَ | | قبلها فتحة | up
- يُنْشِئُ | | قبلها كسرة | down
- تَكافُؤٌ | | قبلها ضمّة | flat
- كُفْءٌ | | قبلها سكون | cross

::rule
@map حركةُ ما قبلها | حركةُ الهمزة لا تهمّ
- فتحة ← أ | | قَرَأَ · مَلْجَأ · مَبْدَأ | up
- ضمّة ← ؤ | | تَباطُؤ · لُؤْلُؤ · تَكافُؤ | flat
- كسرة ← ئ | | شاطِئ · قارِئ · يُنْشِئ | down
- سكون أو مدّ ← ء | | جُزْء · دِفْء · سَماء · هُدوء · بَريء | cross
@map متوسّطة أم متطرّفة؟
- المتوسّطة | حركتُها + حركةُ ما قبلها ← الأقوى | | home
- المتطرّفة | حركةُ ما قبلها فقط | | pointer
@parse
جُزْ=سكون ; ءًا=على السّطر + ألف
شَيْـ=سكون ; ئًا=على النّبرة (حرفٌ يتّصل)
@remember غطِّ الهمزةَ بإصبعك وانظرْ إلى الحرف الّذي قبلها : حركتُه هي الّتي تختارُ الكرسيّ!

::tip نصيحةُ فيدو
عندما تكتبُ همزةً في آخر الكلمة، غطِّ الهمزةَ بإصبعك وانظرْ إلى الحرف الّذي قبلها : ما حركتُه؟ هي الّتي تختارُ لك الكرسيّ!

::ex classify 1 | أُصنّفُ الكلماتِ حسبَ رسم الهمزة المتطرّفة

على الألف (أ): مَلْجَأ - قَرَأَ - مَبْدَأ
على الواو (ؤ): تَباطُؤ - لُؤْلُؤ - تَكافُؤ
على الياء (ئ): شاطِئ - قارِئ - يَبْتَدِئ
على السّطر (ء): جُزْء - دِفْء - سَماء - هُدوء

::ex mcq 2 | أختارُ الرّسمَ الصّحيح
{*هُدوء | هُدوؤ | هُدوئ} اللَّيْلِ جَميلٌ.
جَلَسْتُ عَلى {الشّاطِأ | *الشّاطِئ | الشّاطِؤ}.
لَمْ {*يَبْدَأْ | يَبْدَئْ | يَبْدَؤْ} الدَّرْسُ بَعْدُ.
اِشْتَرَيْتُ {*شَيْئًا | شَيْءًا | شَيْأً} جَميلًا.

::ex fix 3 | أُصحّحُ الأخطاءَ وأُعلّل
جَلَسْتُ عَلى الشّاطِأ. => الشّاطِئ (ما قبلها مكسور)
هٰذا الإِناءُ مَمْلوؤ. => مَمْلوء (بعد واو المدّ : على السّطر)
قَرَئَ الوَلَدُ القِصَّةَ. => قَرَأَ (ما قبلها مفتوح)
التَّباطِئ في العَمَلِ عَيْبٌ. => التَّباطُؤ (ما قبلها مضموم)

answer: إجابة ممكنة : جَلَسْتُ عَلى الشّاطِئِ (كسرة ← ئ) في هُدوءٍ (حرف مدّ ← ء)، وَرَأَيْتُ قارِبًا يَلْجَأُ (فتحة ← أ) إلى المَرْفَإِ.
