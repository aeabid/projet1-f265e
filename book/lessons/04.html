الوظائف

ملخّص الدّرس : كيف أجدُ المتمّماتِ بطرحِ الأسئلة ؟

ما هي المتمّمات ؟

الجملةُ الفعليّة الأساسيّة : فعل + فاعل. نُضيفُ إليها كلماتٍ تُتمّمُ المعنى : أين ؟ متى ؟ لماذا ؟ كيف ؟ ... هذه الكلماتُ هي المتمّمات، وكلُّها منصوبة.

خَرَجَ التَّلاميذُ مَساءً مِنَ المَدْرَسَةِ فَرِحينَ.

أطرحُ السّؤالَ دائمًا بهذا التّرتيب : أداةُ الاستفهام + الفعل + الفاعل ← فالجوابُ هو الوظيفة.
الوظيفةالسّؤالالمثالالجواب
الفاعلمَنْ / ماذا + الفعل ؟قَرَأَ سامي القِصَّةَ.مَنْ قَرَأَ ؟ ← سامي
المفعول بهماذا / مَنْ + الفعل + الفاعل ؟قَرَأَ سامي القِصَّةَ.ماذا قَرَأَ سامي ؟ ← القِصَّةَ
المفعول فيه للمكانأَيْنَ + الفعل + الفاعل ؟جَلَسَ القِطُّ تَحْتَ الطّاوِلَةِ.أَيْنَ جَلَسَ القِطُّ ؟ ← تَحْتَ
المفعول فيه للزّمانمَتى + الفعل + الفاعل ؟اِسْتَيْقَظَ سامي صَباحًا.مَتى اسْتَيْقَظَ سامي ؟ ← صَباحًا
المفعول لأجلهلِماذا + الفعل + الفاعل ؟وَقَفَ التَّلاميذُ احْتِرامًا لِلْمُعَلِّمِ.لِماذا وَقَفَ التَّلاميذُ ؟ ← احْتِرامًا
الحالكَيْفَ + الفعل + الفاعل ؟عادَ الجُنْدِيُّ مُنْتَصِرًا.كَيْفَ عادَ الجُنْدِيُّ ؟ ← مُنْتَصِرًا

المفعول فيه (الظّرف)

  • للمكان : فَوْقَ - تَحْتَ - أَمامَ - وَراءَ - خَلْفَ - بَيْنَ - يَمينَ - يَسارَ - عِنْدَ - قُرْبَ
  • للزّمان : صَباحًا - مَساءً - لَيْلًا - نَهارًا - يَوْمًا - ساعَةً - غَدًا - قَبْلَ - بَعْدَ

المفعول لأجله والحال

  • المفعول لأجله : يُبيّنُ سببَ الفعل، وهو مصدرٌ غالبًا : حُبًّا - خَوْفًا - طَلَبًا - احْتِرامًا
  • الحال : يُبيّنُ هيئةَ الفاعل أو المفعول به عند وقوع الفعل : مُسْرِعًا - ضاحِكًا - فَرِحًا
«في الحَديقَةِ» تُجيبُ عن «أَيْنَ ؟» لكنّها ليست مفعولًا فيه، بل هي مركّبٌ بالجرّ (حرف جرّ + اسم مجرور). المفعولُ فيه اسمٌ منصوب : أَمامَ البَيْتِ - صَباحًا.
المتمّماتُ كلُّها منصوبة : مفعول به - مفعول فيه للمكان - مفعول فيه للزّمان - مفعول لأجله - حال.

الجملةالسّؤالالوظيفة
شَرِبَ الطِّفْلُ الحَليبَ.

التّمرين 3 : أُكملُ الجملةَ بالمتمّم المطلوب★★ متوسّط
  1. وَصَلَ القِطارُ (مفعول فيه للزّمان)
  2. وَقَفَتِ السَّيّارَةُ المَنْزِلِ. (مفعول فيه للمكان)
  3. رَجَعَ الفَريقُ (حال)
  4. تَصَدَّقَ الرَّجُلُ في الأَجْرِ. (مفعول لأجله)
  5. قَطَفَ الفَلّاحُ (مفعول به)
التّمرين 4 : أُحدّدُ وظيفةَ كلّ كلمةٍ ملوّنة★★ متوسّط

خَرَجَ الصَّيّادُ فَجْرًا، وَرَكِبَ قارِبَهُ مُسْرِعًا. أَلْقى الشَّبَكَةَ وَسَطَ البَحْرِ، وَانْتَظَرَ طَمَعًا في صَيْدٍ وَفيرٍ.

الصَّيّادُفَجْرًاقارِبَهُمُسْرِعًاوَسَطَطَمَعًا

  2. جَلَسَ الجَدُّ في البَيْتِ. ← «في البَيْتِ» :
  3. طارَ العُصْفورُ فَوْقَ الشَّجَرَةِ. ← «فَوْقَ» :
  4. أُعلّلُ :
التّمرين 6 : أُوسّعُ الجملةَ بإضافة المتمّمات المطلوبة★★★ صعب

الجملة : لَعِبَ الأَطْفالُ. ← أُضيفُ : مفعولًا فيه للزّمان + مفعولًا فيه للمكان + حالًا.

الجملة : ذَهَبَتْ سَلْمى. ← أُضيفُ : مفعولًا فيه للزّمان + مفعولًا لأجله.

إصلاح تمارين الدّرس 4

التّمرين 1

المفعول به ← ماذا ؟ / مَنْ ؟ - المفعول فيه للمكان ← أَيْنَ ؟ - المفعول فيه للزّمان ← مَتى ؟ - المفعول لأجله ← لِماذا ؟ - الحال ← كَيْفَ ؟

التّمرين 2
السّؤالالوظيفة
ماذا شَرِبَ الطِّفْلُ ؟مفعول به
أَيْنَ نامَ القِطُّ ؟مفعول فيه للمكان
مَتى سافَرَ أَبي ؟مفعول فيه للزّمان
كَيْفَ دَخَلَتْ مَرْيَمُ القِسْمَ ؟حال
لِماذا اجْتَهَدَ التِّلْميذُ ؟مفعول لأجله
التّمرين 3 (إجابات ممكنة)

صَباحًا - أَمامَ المَنْزِلِ - مُنْتَصِرًا - طَمَعًا في الأَجْرِ - التُّفّاحَ

التّمرين 4

الصَّيّادُ : فاعل - فَجْرًا : مفعول فيه للزّمان - قارِبَهُ : مفعول به - مُسْرِعًا : حال - وَسَطَ : مفعول فيه للمكان - طَمَعًا : مفعول لأجله

التّمرين 5

أَمامَ : مفعول فيه للمكان - في البَيْتِ : مركّب بالجرّ - فَوْقَ : مفعول فيه للمكان. التّعليل : المفعولُ فيه اسمٌ منصوب، أمّا «في البَيْتِ» فتبدأُ بحرف جرّ والاسمُ بعدَها مجرور.

التّمرين 6 (إجابات ممكنة)

لَعِبَ الأَطْفالُ مَساءً قُرْبَ البَيْتِ فَرِحينَ. - ذَهَبَتْ سَلْمى صَباحًا إلى السّوقِ طَلَبًا لِلْخُضَرِ.
