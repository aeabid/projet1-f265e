# صناعة العادات (النسخة 2)

تطبيق تحفيز على الطاعات بهوية مركز فيد: مهام يومية متكرّرة وتحديات خاصة، والكل يتنافس في ترتيب أسبوعي.

- **اليوم:** بطاقة البطل (النقاط، المستوى، أيام النشاط المتتالية 🔥، الشارات، ترتيب الأسبوع و«ينقصك X نقطة لتتجاوز فلان»)، حلقة تقدّم اليوم، المهام اليومية بزرّ كبير (والصلوات الخمس صلاة صلاة)، آخر 7 أيام لكل مهمة، وحديث صحيح يتغيّر كل يوم.
- **التحديات الخاصة (مرة واحدة):** قراءة PDF (رابط أو ملف يرفعه المشرف)، فيديو يوتيوب يجب مشاهدته فعلًا حتى آخره (القفز لا يُحتسب)، وسؤال تحقّق اختياري. آخر أجل وعدّاد «باقي X أيام».
- **النقاط والمكافآت:** نقاط كل مهمة، ✨ مكافأة اليوم المثالي (كل المهام اليومية)، 🔥 مكافأة كل 7 أيام متتالية في مهمة. المشرف يحدّد قيمتها.
- **المستويات:** مبتدئ ← مجتهد ← مثابر ← مواظب ← متميّز ← بطل ← نجم ← قدوة ← فارس ← أسطورة.
- **الشارات:** 16 شارة (أول خطوة، أسبوع ذهبي، شهر كامل، يوم/أسبوع مثالي، حارس الصلاة، قارئ، متابع، 100/500/1000 نقطة، المتصدّر…) مع تقدّم كل واحدة.
- **الاحتفال:** قصاصات ملوّنة، «+5» طائرة، صوت (يُطفأ من 🔊)، اهتزاز، ونافذة احتفال عند يوم مثالي أو مستوى أو شارة جديدة.
- **الترتيب:** منصّة الثلاثة الأوائل، ثم جدول بالمستوى والسلسلة والأيام المثالية ونقاط المكافآت؛ الأسبوع / الشهر / منذ البداية، عام أو لكل مهمة.
- **الإدارة:** مهام يومية أو خاصة، إضافة سريعة (الصلوات الخمس، سنّة الفجر، الشفع والوتر، أذكار الصباح، أذكار المساء، ورد القرآن)، ترتيب المهام، مدّة التعمير، المكافآت، القانون، وجدول كل مشارك يومًا بيوم مع التصحيح.

## التقنية

- واجهة ثابتة (`index.html`, `app.js`, `styles.css`) تُنشر على Netlify، مجلّد النشر هو هذا المجلّد.
- Supabase: الحسابات وقاعدة البيانات. المخطط وقواعد الوصول (RLS) في `supabase/schema.sql`.
  - كل واحد يقرأ ويكتب أيامه فقط؛ الترتيب عبر الدالة `leaderboard` التي لا تُرجع تفاصيل الأيام.
  - المشرف (`profiles.is_admin`) يرى ويصحّح كل شيء. المشرف: abid.alaa@gmail.com فقط (في `handle_new_user`)؛ تبويب «الإدارة» لا يظهر لغيره.
- الترتيب: الدالة `ranking2` (`supabase/005_gamification.sql`) تحسب النقاط والمكافآت؛ ملفات PDF في الحاوية العامة `task-files` (الرفع للمشرف فقط).
- النشر: انشر ملفات الواجهة فقط (`index.html`, `app.js`, `styles.css`, `config.js`, الصور، `netlify.toml`) دون مجلّد `supabase/`.
- `config.js`: رابط مشروع Supabase والمفتاح العام (publishable)، وهو مفتاح مخصّص للمتصفح.
