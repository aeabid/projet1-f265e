# صناعة العادات

تطبيق مستقل (لا علاقة له بمركز فيد): كل عادة يومية تحدٍّ، والجميع يرى الترتيب، والمشرف يرى كل التفاصيل.

- **التسجيل:** بالإيميل وكلمة السر دون رسالة تأكيد (الدالة `supabase/functions/signup`)، أو بحساب Google (يظهر زرّه عندما يُفعَّل في Supabase).
- **عدة مشاركين في الحساب الواحد:** الولي يضيف أبناءه، وكل واحد له أيامه وترتيبه.
- **عاداتي:** أيام الأسبوع السبعة كدوائر لكل عادة، السلسلة 🔥، النسبة، والترتيب. تسجيل آخر 7 أيام فقط.
- **النقاط:** المشرف يحدّد نقاط كل مهمة؛ ومهمة بعناصر (مثل الصلوات الخمس) تُسجَّل عنصرًا عنصرًا، ونقاطها لكل عنصر.
- **الترتيب:** ترتيب عام بمجموع النقاط، وترتيب لكل مهمة (أحسن واحد في الصلاة، في القرآن…)، هذا الأسبوع / هذا الشهر / منذ البداية.
- **القانون:** تبويب يراه الجميع، والمشرف يكتبه ويعدّله.
- **الفيديو:** لكل مهمة رابط يوتيوب اختياري يُشاهَد داخل التطبيق.
- **الإدارة:** مدّة تعمير اليوم (اليوم فقط، 48 ساعة، 3 أيام، أسبوع)، إضافة العادات وتعديلها، وجدول كل مشارك وكل يوم مع وقت التسجيل، وتصحيح أي يوم.

## التقنية

- واجهة ثابتة (`index.html`, `app.js`, `styles.css`) تُنشر على Netlify، مجلّد النشر هو هذا المجلّد.
- Supabase: الحسابات وقاعدة البيانات. المخطط وقواعد الوصول (RLS) في `supabase/schema.sql`.
  - كل واحد يقرأ ويكتب أيامه فقط؛ الترتيب عبر الدالة `leaderboard` التي لا تُرجع تفاصيل الأيام.
  - المشرف (`profiles.is_admin`) يرى ويصحّح كل شيء. المشرف: abid.alaa@gmail.com فقط (في `handle_new_user`)؛ تبويب «الإدارة» لا يظهر لغيره.
- `config.js`: رابط مشروع Supabase والمفتاح العام (publishable)، وهو مفتاح مخصّص للمتصفح.
