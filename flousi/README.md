# فلوسي — مداخيلي ومصاريفي

تطبيق مستقل (لا علاقة له بتطبيق فيد): صفحة واحدة `index.html` + قاعدة بيانات على Supabase.

- **الحسابات خاصة بفلوسي.** أول حساب يُنشأ يصبح **المسؤول**. كل حساب يرى عملياته فقط.
- **المسؤول:** يدير الأنواع (إضافة، اسم، رمز، لون، ترتيب، إيقاف/إرجاع)، ويفتح أو يغلق إنشاء الحسابات، ويجعل حسابًا مسؤولًا أو يحذفه.
- **الدخول بـ Google:** المسؤول يضع Client ID (Google Cloud ← Credentials ← OAuth client ID ← Web application،
  و Authorized JavaScript origins = رابط فلوسي) في «الإدارة ← الحسابات». قاعدة البيانات تتحقق من الرمز عند Google نفسه
  (الإضافة `http`). حساب Google جديد يُنشأ إن كان التسجيل مفتوحًا، وأي حساب بكلمة سر يمكن ربطه بـ Google من «الإعدادات».
- **الإحصائيات:** يوم / أسبوع / شهر / سنة / مدة، المقارنة بالفترة السابقة، رسم يومي أو شهري، توزيع حسب النوع، بحث، تصدير CSV.

- **يومي (جدول أسبوعي):** الأيام × الساعات. اسحب الخانة لتغيير وقتها أو يومها، واسحب حافّتها السفلى لتغيير المدّة
  (باللمس: ضغطة مطوّلة ثم سحب)، واضغط مكانًا فارغًا للإضافة. **الجدول الأساسي** يُنسخ في كل أسبوع، وكل أسبوع يُعدَّل وحده
  (مع «إرجاعه إلى الأساسي» و«اجعله الجدول الأساسي»، وخيار تطبيق التعديل على الأساسي أيضًا).
- **المواعيد:** موعد بتاريخ ووقت وملاحظة، يظهر في الجدول وفي «مواعيدي القادمة»، مع زرّ إضافته إلى تقويم Google للتذكير على الهاتف.
- **عاداتي:** أربعة أنواع: نعم/لا، عدد (الأكثر أفضل، مثل صلوات الجماعة من 5 بأسمائها)، عدد (الأقل أفضل، مثل الغضب مع
  المقارنة بالأسبوع الماضي)، وورد القرآن (من سورة/آية إلى سورة/آية، مع الموضع الذي وصلت إليه ونسبة الختمة).
  الأيام بأسمائها وتواريخها، والتسجيل لأي يوم سابق، والسلسلة 🔥، وحصيلة الشهر.

## قاعدة البيانات

`supabase/schema.sql` ثم `supabase/002_day_habits.sql` ثم `supabase/003_week_table_habit_kinds.sql`، كل واحد مرة واحدة في SQL Editor. الجداول في المخطط الخاص `flousi` (غير مفتوح للـ API)،
والمتصفح لا يصل إلا إلى الدوال `public.flousi_*` بالمفتاح العمومي (publishable). كلمات السر مشفّرة (bcrypt)،
والجلسات تُحفظ ببصمتها فقط، و10 محاولات دخول خاطئة توقف الحساب ربع ساعة.

عنوان المشروع والمفتاح العمومي في أعلى السكربت في `index.html` (`SUPABASE_URL`, `SUPABASE_KEY`).

موقع Netlify مستقل: Base directory = `flousi`، Publish directory = `flousi` (أو سحب المجلد في Netlify Drop). لا بناء ولا دوال.
